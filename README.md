## 🚀 How to Run the Scripts

Clone the repository:

```bash
git clone https://github.com/abhi2330/Practice_shellscript.git
```

Move into the project:

```bash
cd Practice_shellscript
```

Give execute permission to a script:

```bash
chmod +x day1/check_file_exits.sh
```

Run the script:

```bash
./day1/check_file_exits.sh
```

You can follow the same process for other `.sh` files.
